# 示例输入：抖音产品经理 JD

> 本文件模拟一份真实 JD 输入，用于演示 job-match-advisor 的工作效果。
> JD 故意包含：含糊表述（展示隐含要求识别）、部分 gap 项（展示诚实诊断）。

---

## 原始 JD（用户粘贴形式）

```
【岗位】抖音 · 创作者产品 · 产品经理实习生

【业务介绍】
抖音创作者产品团队负责面向内容创作者的全链路工具和激励体系，帮助更多创作者在平台上实现商业化价值和内容影响力。

【岗位职责】
1. 参与创作者成长体系、激励机制等产品方向的设计与迭代
2. 独立完成用户调研（访谈/问卷设计），输出调研报告
3. 撰写完整的 PRD 并跟进需求从立项到上线的完整流程
4. 对已上线功能进行数据分析，支持产品迭代决策
5. 在跨职能团队（设计/研发/数据/运营）中推动需求落地

【岗位要求】
1. 在校学生，可实习时间 3 个月以上优先
2. 有较强的逻辑分析能力，能用数据说话
3. 有产品经理实习经验者优先，有内容/社区/创作者相关产品经验者加分
4. 熟悉基本数据分析工具，有 SQL 基础优先
5. 有良好的沟通表达能力和跨部门协调能力
6. 对内容生态/创作者经济有深度理解和浓厚兴趣

【加分项】
- 有过独立 App 或小程序的开发/设计经历
- 本身是活跃创作者（抖音/B站/小红书等平台）
```

---

## 预期的 JD 拆解结果（用于验证工具）

| ID | 维度 | 要求 | 原文 | 等级 | 难度 |
|----|------|------|------|------|------|
| HS-01 | 硬技能 | 独立用户调研（访谈+问卷设计） | "独立完成用户调研" | 必须 | 基础 |
| HS-02 | 硬技能 | PRD 撰写 + 全流程跟进 | "撰写完整的 PRD 并跟进" | 必须 | 基础 |
| HS-03 | 硬技能 | 数据分析支持产品决策 | "数据分析，支持产品迭代决策" | 必须 | 基础 |
| HS-04 | 硬技能 | SQL 基础 | "有 SQL 基础优先" | 优先 | 基础 |
| SS-01 | 软技能 | 跨职能团队推动落地 | "在跨职能团队中推动需求落地" | 必须 | 进阶 |
| SS-02 | 软技能 | 结构化表达/沟通 | "良好的沟通表达能力" | 必须（隐含） | 基础 |
| BA-01 | 业务理解 | 内容生态/创作者经济认知 | "对内容生态/创作者经济有深度理解" | 必须 | 进阶 |
| PL-01 | 加分项 | 独立产品经验 | "独立 App 或小程序" | 加分 | — |
| PL-02 | 加分项 | 本身是内容创作者 | "本身是活跃创作者" | 加分 | — |

**隐含要求识别**：
- "有较强的逻辑分析能力" → 开放分析题会考框架拆解，不是只看工具
- "在跨职能团队中推动" → 不只是"良好配合"，而是"主动推动"，考察 owner 意识
- "对内容生态有深度理解" → 会出认知类题目，不能靠背行业报告应付
