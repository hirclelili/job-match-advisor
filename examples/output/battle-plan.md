# 第一章：岗位概览

## 这个岗位在做什么

创作者产品团队负责抖音平台内容生产侧——帮创作者更好地创作、成长、变现。你做的产品不面向普通用户，面向"给平台供给内容的人"，这批人是平台内容生态的基础。

实习生在这个团队通常被分配一个具体的产品方向（如成就体系、工具功能、激励规则），在 mentor 指导下独立负责从调研到上线的全流程。字节实习生不是打杂的——你大概率会有真实的 PRD 产出和上线经历。

## 核心挑战

- 创作者需求复杂，头部/腰部/尾部创作者动机差异很大，产品需要精细化分层设计
- 功能效果需要数据验证，不能靠感觉说话
- 跨团队协调要求高（设计/开发/数据/运营），推动落地是真实难点

## 公司类型与面试风格预判

**公司类型**：字节跳动 · 大厂

**面试风格预判**：
- 通常 3 轮面试：1 轮 HR 初筛 + 2 轮业务面（含 mentor 或 team leader）
- 喜欢追问细节："你刚才说留存提升了 11%，这个数字是怎么算的？"
- 高频考察：数据意识 + 跨部门推动 + 用户洞察
- 对"创作者产品"有行业认知会明显加分
- 如果简历里有抖音相关经历，几乎必被深挖

## 真 gap（🔴）应对策略

### Gap 1：SQL 基础（HS-04）

- **gap 类型**：可弥补型（技能 gap，面试前有可能突击）
- **面试应对**：
  > "SQL 这块我目前还没有实际使用过，但我已经在跟 [具体课程/教程，如 w3school SQL tutorial]，能做基本的查询和聚合。字节的产品岗我了解通常需要用 SQL 取数，我会尽快把这个补上。"
- **面试前可做的行动**：
  - 距面试 1 周以上：完成 SQL 基础语法 + 常用聚合函数 + 简单 JOIN（3-5 天可完成）
  - 准备 1 个场景：如"如果我要看创作者留存率，SQL 查询的逻辑是..."
  - 实在来不及：诚实说在学，比假装会更好

### Gap 2：独立 App/小程序经历（PL-01）

- **gap 类型**：难弥补型（加分项，不影响核心评估）
- **面试应对**：这是加分项，不主动提，如果被问到直接说"这块还没有机会，不过我在 [相关学习/兴趣] 上有一些接触"即可。不需要刻意补救。
