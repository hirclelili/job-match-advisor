## 隐含要求识别

- **"有较强的逻辑分析能力"** → 实际要求：开放分析题会考框架拆解，不是只看工具熟练度；需要能口头展示"拆解问题的过程"
- **"在跨职能团队中推动需求落地"** → 实际要求：不只是配合执行，而是 owner 角色——发现问题、推动排期、闭环上线
- **"对内容生态有深度理解"** → 实际要求：会出认知类开放题（"你怎么看创作者激励体系"），不能靠背行业报告应付，需要有自己的视角

## 拆解备注

HS-04（SQL）写的是"优先"而非"必须"，但字节产品岗实际上几乎都会用 SQL 取数，属于"写着优先，实际上是基础配置"的情况。如果没有 SQL 经验，面试前值得做一下基础学习。

BA-01 的"深度理解"比较主观，面试中通常通过一道开放题来考（"你怎么看创作者激励"），是非常高权重的题目，不要轻视。
